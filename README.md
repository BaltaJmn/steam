# The Floor Is Bricks (nombre provisional)

> Todo el mundo sabe lo que pasa cuando pisas una.

Juego coop (1–4), simple, creamy, lofi y minimalista para Steam. Una habitación tranquila al atardecer con 10 mesas y el suelo lleno de piezas de construcción mezcladas. Hay que buscarlas y llevarlas a las mesas: cada una tiene su clasificador, se queda con las piezas que necesita y va montando una figura sencilla. Hay mejoras y ayudantes de cuerda que automatizan el trabajo.
